# Edlawit Bekere portfolio

A responsive, buildless portfolio for curation and moving image. Built with semantic HTML, CSS and vanilla JavaScript.

## Local preview

Serve this directory with any static HTTP server, such as `python -m http.server 3000`, then visit http://localhost:3000. No package installation or build step is required.

## Update content

Edit `content.js` to update project descriptions, image URLs and film entries. Replace stock image URLs with project photographs and update their alt text. Remove the reference-imagery labels and stock disclaimer only after the relevant images have been replaced. Hero imagery is in `index.html`.

To enable a film, set its `youtubeId` in `content.js` to the 11-character YouTube video ID. A privacy-enhanced YouTube player appears automatically. Update the forthcoming language when films are ready.

Biography and contact links are in `index.html`; visual styling is in `styles.css`.

## Deployment

Import this repository into Vercel. Select Other as the framework, no build command, and the repository root as the output directory.

## Content provenance

Professional experience and contact details were provided in the portfolio questionnaire. No dates, awards, clients, testimonials or outcomes have been invented. Images are temporary Unsplash references, credited in the site. They do not document the named exhibitions. Films remain explicitly upcoming until original links are provided. The questionnaire itself is not included in this public repository.
